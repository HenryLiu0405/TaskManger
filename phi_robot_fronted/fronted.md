# 九宫格锁屏式组件页面设计

## 1. 页面目标
这个页面只展示一个九宫格锁屏式交互组件，不再保留空白对话框、业务面板、日志区或其他辅助模块。

页面下方只保留两个按钮：`运行` 和 `强制暂停`。其中 `运行` 是一个可切换状态的按钮，点击后文本变为 `运行中`，再次点击后恢复为 `运行`；`强制暂停` 暂时只占位，不做实际处理。
当前交互里，九宫格默认可以滑动，但当 `运行` 进入 `运行中` 时，九宫格会停止接受滑动输入。

## 2. 页面结构

### 2.1 中央锁屏组件
- 页面视觉中心是一个 3 x 3 的九宫格。
- 九个圆点等间距排列，整体像手机锁屏解锁面板。
- 用户在非运行中状态下按住鼠标滑动时，经过的圆点会点亮并形成连线。
- 用户在运行中状态下无法继续滑动九宫格。
- 已连接过的圆点不能再次连接，也不会再次点亮。

### 2.2 底部按钮区
- 锁屏组件下方只放两个按钮。
- `运行` 按钮负责切换运行态展示，运行中时会禁用九宫格滑动。
- `强制暂停` 仅保留按钮本身，当前不接入逻辑。

## 3. 交互规则
- 非运行中时，鼠标按下后，组件进入绘制态。
- 运行中时，组件进入阻止绘制的状态。
- 首次经过某个圆点时，该点会被连接并点亮。
- 如果后续路径再次经过这个圆点，系统不再允许连接它。
- 路径只记录首次有效连接，不做重复节点反转或取消点亮。
- 松开鼠标后结束本次绘制，保留当前路径结果。

## 4. 视觉风格
- 保持深色、克制、科技感的界面风格。
- 重点突出九宫格节点和连线路径。
- 用发光、描边和微弱阴影来强调已连接节点。
- 不使用调度台、列表、日志或其他复杂布局。

## 5. 静态页面范围
- 不接入后端。
- 不保留聊天输入区。
- 不保留业务卡片、日志卡片或多余状态区。
- 页面只有九宫格锁屏组件和下方两个按钮。

## 6. 设计结论
这是一个极简的锁屏式交互页面：中间只看九宫格，下方只看两个按钮。核心规则是“连接过的圆点不可再次连接”，并且“运行中时九宫格不能滑动”，而不是运行中才开始允许滑动。`运行` 负责切换运行态，`强制暂停` 先预留入口，后续再补逻辑。
