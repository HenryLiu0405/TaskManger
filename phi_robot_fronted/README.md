# phi_robot Fronted

一个独立运行的 React 前端项目，用于展示搬运调度型 Demo。页面采用拖拽编排器形式，不再是控制台。

## 功能

- 左侧拖拽排序队列，拖拽顺序就是执行顺序
- 中间六宫格目标区，每个宫格对应现实场地方位
- 右侧提交与执行面板，支持提交修改、开始执行和重置
- 任务卡片支持拖到六宫格内修改搬运方位
- 执行日志和进度条实时展示

## 运行

```bash
npm install
npm start
```

然后打开：

```text
http://127.0.0.1:4173
```

## 验收

```bash
npm test
```

## 说明

这个项目不依赖 `nanobot`，前端逻辑完全独立。任务必须先拖拽完成顺序和方位，再点击“提交修改”，之后才能点击“开始执行”。
